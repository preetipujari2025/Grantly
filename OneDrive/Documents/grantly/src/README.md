# 💜 GRANTLY – Unified Scholarship Discovery & Management Platform

### Big Dreams. Real Opportunities.

GRANTLY is a modern scholarship discovery and management platform designed to simplify the process of finding, matching, and managing educational scholarship opportunities.

It provides students with a centralized platform to discover scholarships, check eligibility, track applications, and stay updated on important deadlines.

---

## ✨ Features

- 🎓 **Student Dashboard** – Personalized dashboard with scholarship statistics and recommendations.
- 🔍 **Scholarship Discovery** – Explore, search, filter, and sort scholarship opportunities.
- 🎯 **Smart Scholarship Matcher** – Find scholarships based on academic and financial eligibility criteria.
- 📌 **Saved Scholarships** – Bookmark opportunities for future reference.
- 📊 **Application Tracker** – Track application progress and update application statuses.
- 📅 **Deadline Tracker** – Monitor upcoming scholarship application deadlines.
- 👤 **Student Profile** – Manage academic and personal information.
- 💫 **Interactive UI** – Smooth animations, 3D-inspired illustrations, and responsive layouts.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project

```bash
cd grantly
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Build for production

```bash
npm run build
```

## 🎯 Problem Statement

Students often face difficulties discovering relevant scholarship opportunities, understanding eligibility criteria, managing applications, and tracking deadlines.

GRANTLY aims to simplify this journey through a unified digital platform that makes scholarship discovery and management easier, more intuitive, and accessible.
